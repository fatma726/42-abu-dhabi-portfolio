# Rank 04 · NetPractice

## Objective

Solve IPv4 subnetting and routing puzzles by applying address rules rather than guessing.

## What it teaches

Binary masks, network and broadcast addresses, host ranges, gateways, interfaces, and routing tables.

## Workflow

`read topology → convert addresses to binary → apply mask → derive network/range → assign valid hosts/gateways → verify every route`. Write the calculation beside each answer so the reasoning is reproducible.

## Usage and evaluation tips

Complete the provided browser training interface. Retry deliberately wrong masks to learn from the feedback. A strong evaluation explains why an address is inside a subnet, not only that it passes.

## Common mistakes and improvements

Confusing a host with the network address, assigning a gateway outside its subnet, and using reserved network/broadcast addresses are common. Improve with a small binary worksheet or an offline subnet calculator written from scratch.

## What I learned

Networking becomes manageable when each address is checked against one precise rule.
