## Why some projects are lessons only

The public portfolio must be honest. I found downloaded or shared repositories whose file headers, remotes, or commit history identify other developers. They remain private or are represented by lessons only. Business-facing DLD counter repositories also remain private because they contain live Firebase configuration and operational branding.

## Source notes

- Build artifacts, binaries, `.DS_Store` files, tester outputs, and local editor settings are excluded.
- Cub3D's MiniLibX dependency is not republished; install the platform-appropriate library separately.
- The source folders are snapshots for learning and review. Keep 42 school rules and any partner attribution visible when you extend them.
